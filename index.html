ABOUT

Subway Web Arcade

這個專案使用原生 HTML、CSS、JavaScript 與 Canvas 製作，不需要 Node.js 或資料庫即可部署到 GitHub Pages。

控制

  • 左右：切換軌道
  • 跳躍：跨越低障礙
  • 滑行：通過高障礙
  • Esc / Start：暫停
  • R：死亡後重新開始

重要

本專案使用原創的程式化圖形與音效，不包含官方 Subway Surfers 的遊戲檔、角色、貼圖或音樂。主題名稱也可自行修改。
